# Security Architecture & Threat Model — Urban Air Quality Assistant

## 1. Security Posture Summary

Every boundary (client forms, Next.js API routes, upstream Open-Meteo/LLM clients, HTTP response headers, and structured server logs) enforces fail-closed validation, privacy protection, and defense-in-depth with **zero client-exposed secrets**.

- **Zero Secrets in Client Bundle**: `src/lib/env.ts` rejects any `NEXT_PUBLIC_*` variable whose name contains `key`, `secret`, `token`, or `password` whenever populated. LLM keys (`GEMINI_API_KEY`, `ANTHROPIC_API_KEY`) are read strictly on the server.
- **No Unvalidated Input**: All query strings, coordinates, enums, and JSON payloads are validated with Zod (`src/services/schemas.ts`), returning typed `400 VALIDATION_ERROR` responses on violation.
- **No `dangerouslySetInnerHTML`**: Zero HTML injection paths exist anywhere in the codebase; assistant replies and user messages render as plain text (`src/components/AirQualityChat.tsx`) after tag stripping (`sanitizeAssistantOutput`).
- **Privacy by Default**: Browser coordinates are held in transient React state solely for `/api/air-quality` requests, never persisted to `localStorage` (`saveCachedSnapshot` skips `geo-self-*` keys), never written to cache headers (`private, no-store` for coordinate queries), and rounded to 2 decimals (~1.1 km) in server logs (`src/lib/logger.ts`).

## 4. GenAI Safety Controls (`src/services/assistant.ts`)

1. **Input Sanitization & Cap**: Messages limited to `MAX_CHAT_MESSAGE_LENGTH` (500 characters) via Zod; `sanitizeUserPrompt` strips Unicode control characters (`\u0000-\u001F`, bidi/zero-width markers) and model delimiter tokens (`<|...|>` / `[INST]` / `<<SYS>>` / `### System:`).
2. **Adversarial & Off-Topic Guard**: Known override, jailbreak, and secret-exfiltration queries trigger immediate deterministic refusal (`refused: true`). Non-air-quality topics are declined with a helpful domain scope reminder.
3. **Strict Data Grounding**: Upstream `airQualityContext` metrics (validated numeric bounds) are serialized into a read-only `DATA_JSON` block; the system prompt instructs Gemini/Anthropic to cite only provided figures, include daily low-emission routines / indoor hacks, stay within `MAX_LLM_OUTPUT_TOKENS` (450), and append a non-medical disclaimer.
4. **Zero-Key Fallback Parity**: When neither `GEMINI_API_KEY` nor `ANTHROPIC_API_KEY` is configured (or `LLM_PROVIDER=fallback`, or an upstream LLM call fails), `buildDeterministicReply` generates accurate localized (`en`/`hi`/`ta`) answers computed strictly from fetched city numbers.

## 5. Responsible Disclosure Policy

If you discover a security issue in Urban Air Quality Assistant:

1. **Do not** open a public GitHub issue with working exploit details or credentials.
2. Send a minimal reproduction report privately to the project maintainer (`Sayandevxyz` via GitHub Security Advisories on the repository).
3. Include affected file path(s), HTTP request/payload example, expected vs. actual behavior, and suggested mitigation if known.
4. Maintainers aim to acknowledge reports within 48 hours and publish a patched release and advisory once verified.
