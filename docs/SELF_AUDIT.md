4. Static hygiene & security scan across `src/` (`any`, `@ts-ignore`, `console.log`, `dangerouslySetInnerHTML`, `TODO`/`FIXME`, hardcoded keys, `NEXT_PUBLIC_*` secret leaks -> `0` hits)

6. `npm run test:e2e` (Playwright Desktop + Mobile E2E, keyboard navigation, security headers, 320 px overflow, and `@axe-core/playwright` light/dark WCAG 2.2 audits)
